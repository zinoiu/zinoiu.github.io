# zinoiu.github.io

My portfolio website: https://zinoiu.github.io

I'm an aspiring cybersecurity analyst. The site shows my projects, my Cisco Networking Academy courses, and how to contact me.

## What's on the site

- Projects: Upang Delivers, InvestEd, Rows of Victory, Translate Go, and Elemental Elegance
- Security: courses, certificates, and secure web development work
- About and contact details

The hero has a small Tic-Tac-Toe game that two people can play on one screen.

## Built with

HTML, CSS, and a little JavaScript. One file (`index.html`), no frameworks, no build step.

## Run it locally

Download the repo and open `index.html` in a browser.
